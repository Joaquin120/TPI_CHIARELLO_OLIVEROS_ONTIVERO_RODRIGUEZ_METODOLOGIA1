# 04. Stack Tecnológico

- **Lenguaje principal:** Python 3.11+ / Node.js (según configuración base del repositorio).
- **Framework Web / API:** FastAPI / Express / Flask.
- **Base de datos:** SQLite (para desarrollo y testing) / PostgreSQL.
- **Framework de Testing:** Pytest / Jest para la ejecución de suites unitarias e integrales.
- **Gestión de Entorno:** Entornos virtuales (`venv`) y variables de configuración `.env`.
