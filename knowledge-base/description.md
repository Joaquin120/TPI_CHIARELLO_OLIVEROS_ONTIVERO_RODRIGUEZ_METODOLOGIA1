# Descripción del Sistema

## Alcance del MVP
El sistema permite el registro, consulta y administración de turnos odontológicos asegurando la no colisión de recursos mediante el motor de validación bidireccional.

## Módulos Principales
- Gestión de profesionales y sillones.
- Agenda de turnos con ciclo de vida completo (PENDIENTE, CONFIRMADO, CANCELADO, COMPLETADO).
