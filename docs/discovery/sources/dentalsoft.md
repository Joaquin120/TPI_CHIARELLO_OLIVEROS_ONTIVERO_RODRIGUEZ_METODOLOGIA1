# DentalSoft

- **Sitio web:** https://www.dentalsoft.com.ar/ (y portales asociados de gestión)
- **Tipo de solución:** Software de escritorio con sincronización cloud / Híbrido
- **País de origen / Foco:** Argentina / LATAM
- **Fecha de consulta:** Octubre 2026

## Hallazgos y Evidencias
- **Gestión de sillón / box:** No evidenciado en su versión estándar; la agenda se estructura por profesional tratante.
- **Recordatorios a pacientes:** Módulo básico de envío de correos electrónicos.
- **Odontograma / Ficha clínica:** Cuenta con odontograma tradicional 2D (piezas dentarias numeradas FDI) y registro de prestaciones por cara dental.
