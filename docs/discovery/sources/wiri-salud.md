# Wiri Salud

- **Sitio web:** https://wiri.la/argentina
- **Tipo de solución:** Plataforma web / SaaS de salud ambulatoria
- **País de origen / Foco:** Argentina
- **Fecha de consulta:** Octubre 2026

## Hallazgos y Evidencias

- **Gestión de sillón / box:** No evidenciado. El sistema maneja agenda por profesional de la salud o centro, pero no permite reservar o bloquear infraestructura física específica (sillones dentales).
- **Recordatorios a pacientes:** Confirmación y recordatorio automático vía WhatsApp y correo electrónico.
- **Odontograma / Ficha clínica:** No evidenciado módulo odontológico específico; funciona como turnero médico y gestor de consultas/copagos.
- **Precios y contratación:** Precios públicos en pesos argentinos (ARS) bajo esquema de comisiones por turno y suscripción básica para profesionales.
