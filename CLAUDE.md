# CLAUDE.md - Comandos de Entorno y Verificación

## Comandos Principales
- **Ejecutar Tests:** `pytest`
- **Cobertura de Pruebas:** `pytest --cov=src`
- **Validar Especificaciones:** `openspec validate`

## Estándares de Código
- Python 3.11+
- Tipado estático con Type Hints.
- Cumplimiento de estilo PEP 8.
- Excepciones de dominio explícitas (`SolapamientoProfesionalError`, `SolapamientoSillonError`).
